# 0005. 內容政策：摘要＋編者觀點＋原始連結

- 狀態：已採納
- 日期：2026-10-22

## 背景

網站公開，內容由 AI 根據他人公開發表的文章、演講、Podcast 加工而成。整篇翻譯或轉錄他人作品並公開發布，有著作權風險，也缺乏本站自己的價值。

## 決策

每篇文章由三部分組成：

1. **重點摘要**：AI 以正體中文、用自己的話重新整理原始內容的重點，不得逐句翻譯或照抄原文結構。
2. **編者觀點**：站長寫的心得與評論。這是本站與單純搬運站的差別。
3. **原始來源**：清楚標示原作者、原始標題與連結，並鼓勵讀者讀原文。

具體規則：

- 摘要長度上限：正文（不含編者觀點）**1,200 個中文字**。
- 引用原文：每篇最多 **1 段直接引述**，每段不超過 **25 個英文字**（或等量中文），須加引號並標明出處。
- 摘要與原文的文字重疊必須低於門檻（見 ADR-0009 的「重疊檢查」）。
- 不 commit 原文或逐字稿到公開 repo（見 ADR-0004）。
- 語言：正體中文（臺灣用語），中文標點使用全形。技術名詞可保留英文。
- 發布前**必須**有編者觀點；沒有編者觀點的文章不得改為 `published`。

## 後果

- 法律風險較低，原作者也能獲得導流。
- 每篇都需要站長投入時間寫觀點，發文速度受限於站長；這是刻意的取捨。

## 考慮過的替代方案

- **整篇翻譯**：讀者價值高，但需要授權，且站點本身沒有獨特性。未採用。
- **允許沒有編者觀點的文章發布**：可以加快產量，但會退化成搬運站。未採用；若日後改變，需新 ADR。
